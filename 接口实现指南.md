# 合同智能审批系统 — 后端接口实现指南

> **目的**：你的工程骨架里 `controller` 都是空壳（只有 `@RestController` 和 `@RequestMapping`），`service` 也只是继承了 MyBatis-Plus 的 `IService`。本文档教你如何对照 `接口文档.md` 把这些接口在 Java 后端「写出来」。
>
> **技术栈**：Spring Boot 3.5.6 / Java 21 / MyBatis-Plus 3.5.12 / Spring Security + JWT / Druid / Lombok / fastjson / 统一响应 `R`（`com.ar.contractreview.result`）。
> **根路径**：所有接口都有 `/api` 前缀（`application.yml` 里 `server.servlet.context-path: /api`），所以文档里的 `/user/login` 实际请求是 `/api/user/login`。后端 controller 里不要写 `/api`，只写 `/user/login`。

---

## 0. 一句话结论

- **每个接口 = 一个 Controller 方法 → 调 Service → 用 `com.ar.contractreview.result.R` 返回。**
- **大多数接口是「标准 CRUD」**，复制一套模板即可（列表/详情/新增/更新/删除）。
- **注意 `R.data` 是 `Map<String,Object>`**，返回「单个对象」或「数组」时，前端预期的是 `data` 直接是对象/数组，而当前 `R` 做不到，需要先「增强 `R`」或「返回多个 key」。详见 2.1。

## 2. 通用约定（先看这节，避免踩坑）

### 2.1 统一响应体 `R` —— 关键坑

现在的 `R`：

```java
private Integer code;
private String message;
private Map<String, Object> data = new HashMap<>();
```

- `R.ok()` → `{code:200, message:"请求成功", data:{}}`
- `R.fail(ResponseCode.X)` / `R.fail(code, msg)`
- `R.data("key", value)` → 往 `data` map 里塞一项
- **没有 `timestamp` 字段**。`接口文档.md` 里的 `timestamp` 是前端示意，实际后端不会返回。前端若强依赖 timestamp，需在 `R` 里补一个字段（见下）。

**核心冲突**：前端文档里「单个对象」和「数组」的 `data` 是**直接**对象/数组（例如 `data: { id:1, ... }`、`data: [ {...} ]`）。但当前 `R.data` 是 `Map`，做不到直接放一个 List 或一个实体对象到 `data` 根部。

**建议：增强 `R`（推荐）**，把 `data` 改成 `Object`，同时保留旧的 `.data(key,value)` 用法：

```java
@Data
public class R {
    private Integer code;
    private String message;
    private Object data;          // 改成 Object
    private Long timestamp = System.currentTimeMillis();  // 可选：补上前端要的 timestamp

    private R() {}

    public static R ok() {
        R r = new R();
        r.setCode(ResponseCode.SUCCESS.getCode());
        r.setMessage(ResponseCode.SUCCESS.getMessage());
        return r;
    }
    public static R fail(Integer code, String message) {
        R r = new R();
        r.setCode(code); r.setMessage(message);
        return r;
    }
    public static R fail(ResponseCode rc) {
        return fail(rc.getCode(), rc.getMessage());
    }

    // 直接放一个对象/数组/分页对象到 data 根部
    public R data(Object obj) { this.data = obj; return this; }

    // 兼容旧的键值对用法：data={"k1":v1,"k2":v2}
    public R data(String key, Object value) {
        if (data == null || !(data instanceof Map)) data = new HashMap<>();
        ((Map<String,Object>) data).put(key, value);
        return this;
    }
    // 兼容批量
    public R data(Map<String, Object> map) { this.data = map; return this; }
}
```

改完后：
- 返回单个对象：`return R.ok().data(entity);`         → `data` 就是对象
- 返回数组：`return R.ok().data(list);`               → `data` 就是数组
- 返回分页：`return R.ok().data(pageResultMap);` 或 `.data("list",...).data("total",...)`

> 若不想改 `R`，另一种写法是不用 `data` 根，而是**把每个字段作为 key 放进去**，但这样无法匹配前端文档的 JSON 形状。**强烈建议采用上面的增强版 `R`。** 下面所有示例都假设用的是增强版（`data(Object)`）。

### 2.2 分页（必须先配分页插件，否则不生效）

当前工程**没有配置 MyBatis-Plus 分页拦截器**，直接 `service.page()` 会查出全量、不分页。先在 `config` 里注册：

```java
package com.ar.contractreview.config;

import com.baomidou.mybatisplus.annotation.DbType;
import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class MybatisPlusConfig {
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

分页结果包装（前端期望 `data:{list,total,page,size}`）：

```java
IPage<ContractContract> page = contractContractService.page(
        new Page<>(pageNum, pageSize), queryWrapper);
return R.ok()
        .data("list", page.getRecords())
        .data("total", page.getTotal())
        .data("page", page.getCurrent())
        .data("size", page.getSize());
```

### 2.3 逻辑删除

BaseMapper/IService 的 `deleteById / removeById` 会自动变成 `UPDATE ... SET deleted=-1`（`application.yml` 配了 `logic-delete-value: -1`、`logic-not-delete-value: 0`）。实体上已有 `@TableLogic private Byte deleted;`。**新增/更新不需要关心 deleted 字段。**

### 2.4 条件查询（MyBatis-Plus）

查单个实体/列表多用 `LambdaQueryWrapper`：

```java
LambdaQueryWrapper<ContractContract> qw = new LambdaQueryWrapper<>();
qw.eq(ContractContract::getStatus, status)
  .like(StringUtils.hasText(contractName), ContractContract::getContractName, contractName)
  .orderByDesc(ContractContract::getUploadTime);
List<ContractContract> list = service.list(qw);         // 列表
ContractContract c = service.getOne(qw, false);          // 单个
```

### 2.5 获取当前登录用户

`MyAuthenticationFilter` 把认证信息放进了 `SecurityContextHolder`：`principal` = 用户名，`credentials` = 用户 id。加个工具方法即可取到：

```java
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;

public class SecurityUtils {
    public static String currentUsername() {
        Authentication a = SecurityContextHolder.getContext().getAuthentication();
        return a == null ? null : a.getName();
    }
    public static Long currentUserId() {
        Authentication a = SecurityContextHolder.getContext().getAuthentication();
        return a == null || a.getCredentials() == null ? null : (Long) a.getCredentials();
    }
}
```

### 2.6 权限控制（@PreAuthorize）

`SecurityConfig` 已开启 `@EnableMethodSecurity(prePostEnabled=true, securedEnabled=true)`，角色的权限串是 `ROLE_角色名`（`UserService.wrapRoleAndPerm`），菜单权限是菜单的 `permission` 字符串。用法：

```java
@PreAuthorize("hasRole('ADMIN')")            // 角色
@PreAuthorize("hasAuthority('contract:view')") // 具体权限
```

> 首次做 CRUD 时可以先不写权限注解，跑通后再补。

### 2.7 统一异常

Service 里校验失败就 `throw new BusinessException(ResponseCode.PARAMETER_EXCEPTION)`，`GlobalException` 会返回 `{code,message}`。业务错误码见 `ResponseCode`（如 `PARAMETER_EXCEPTION(100)`、`USERNAME_REPEAT__EXCEPTION(122)`、`NO_PERM_EXCEPTION(403)` 等）。

## 3. 标准 CRUD 完整模板（以「合同 contract_contract」为例）

> 其它模块（模板、条款、规则、风险等级、流程配置、OA、签章、API、配置、备份、用户、角色、菜单、日志）都是同样的套路，只需替换实体。

### 3.1 Service 接口（`service/impl` 里已有基类，只需加自定义方法）

```java
public interface ContractContractService extends IService<ContractContract> {
```

### 3.2 Service 实现（已在 `service/impl/ContractContractServiceImpl.java`）

```java
@Service
public class ContractContractServiceImpl
        extends ServiceImpl<ContractContractMapper, ContractContract>
        implements ContractContractService {

    @Override
    public IPage<ContractContract> pageContract(Integer pageNum, Integer pageSize,
            String contractNo, String contractName, String status) {
        LambdaQueryWrapper<ContractContract> qw = new LambdaQueryWrapper<>();
        qw.like(StringUtils.hasText(contractNo), ContractContract::getContractNo, contractNo)
          .like(StringUtils.hasText(contractName), ContractContract::getContractName, contractName)
          .eq(StringUtils.hasText(status), ContractContract::getStatus, status)
          .orderByDesc(ContractContract::getUploadTime);
        return this.page(new Page<>(pageNum, pageSize), qw);
    }
}
```

### 3.3 Controller（`controller/ContractContractController.java`）

```java
package com.ar.contractreview.controller;

import com.ar.contractreview.entity.ContractContract;
import com.ar.contractreview.result.R;
import com.ar.contractreview.result.ResponseCode;
import com.ar.contractreview.service.ContractContractService;
import com.baomidou.mybatisplus.core.metadata.IPage;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/contracts")
public class ContractContractController {

    @Autowired
    private ContractContractService contractContractService;

    // 5.2 合同列表（分页 + 条件）
    @GetMapping
    public R list(@RequestParam(defaultValue = "1") Integer page,
                  @RequestParam(defaultValue = "20") Integer size,
                  @RequestParam(required = false) String contractNo,
                  @RequestParam(required = false) String contractName,
                  @RequestParam(required = false) String status) {
        IPage<ContractContract> p = contractContractService.pageContract(page, size, contractNo, contractName, status);
        return R.ok().data("list", p.getRecords()).data("total", p.getTotal())
                .data("page", p.getCurrent()).data("size", p.getSize());
    }

    // 5.3 合同详情
    @GetMapping("/{id}")
    public R detail(@PathVariable Long id) {
        ContractContract c = contractContractService.getById(id);
        if (c == null) return R.fail(ResponseCode.PARAMETER_EXCEPTION);
        return R.ok().data(c);
    }

    // 5.4 删除（逻辑删除）
    @DeleteMapping("/{id}")
    public R delete(@PathVariable Long id) {
        contractContractService.removeById(id);
        return R.ok().data(true);
    }
}
```

> **记住**：凡是接口文档里 `data` 是「单个对象/数组」的地方，用增强版 `R` 的 `.data(obj)` / `.data(list)`；凡是要组合多个字段（分页等）用 `.data("list",...).data("total",...)`。

## 4. 特殊接口实现要点

### 4.1 文件上传（`POST /contracts/upload`，multipart/form-data）

```java
@PostMapping("/upload")
public R upload(@RequestParam("file") MultipartFile file,
                @RequestParam String contractName,
                @RequestParam String contractType,
                @RequestParam String partyA,
                @RequestParam String partyB,
                @RequestParam BigDecimal amount,
                @RequestParam(required = false) String signDate,
                @RequestParam(required = false) String startDate,
                @RequestParam(required = false) String endDate) {
    if (file.isEmpty()) return R.fail(ResponseCode.PARAMETER_EXCEPTION);

    // 1) 保存文件到本地/OSS，生成 fileUrl
    String fileUrl = saveFile(file);

    // 2) 组装实体
    ContractContract c = new ContractContract();
    c.setContractNo(generateContractNo());
    c.setContractName(contractName);
    c.setContractType(contractType);
    c.setPartyA(partyA).setPartyB(partyB).setAmount(amount);
    // ... signDate/startDate/endDate 解析为 LocalDate
    c.setFileUrl(fileUrl).setFileType(file.getContentType()).setFileSize(file.getSize());
    c.setStatus("UPLOADED");
    c.setUploadUserId(SecurityUtils.currentUserId());
    c.setUploadUserName(currentUserName());
    c.setUploadTime(LocalDateTime.now());
    c.setCreatedTime(LocalDateTime.now()).setUpdatedTime(LocalDateTime.now());
    contractContractService.save(c);

    return R.ok().data(c);
}
```

`saveFile` 示例（放到 `resources` 外的磁盘目录，并把目录路径配到 yml）：

```java
private String saveFile(MultipartFile file) throws IOException {
    String dir = "D:/contract-files/";
    File folder = new File(dir);
    if (!folder.exists()) folder.mkdirs();
    String filename = UUID.randomUUID() + "_" + file.getOriginalFilename();
    file.transferTo(new File(dir + filename));
    return "/files/contracts/" + filename;
}
```

`generateContractNo()`：可用时间戳 + 序列，如 `"CT" + yyyyMMdd + String.format("%03d", id)`，先保存再回填或先查当日 max。

### 4.2 状态流转（提交审核 / 通过 / 驳回 / 归档）

核心就是**更新 `status` 字段 + 记录审核人/时间/意见**：

```java
// 5.5 提交审核
@PostMapping("/{id}/review")
public R review(@PathVariable Long id, @RequestBody Map<String,Object> body) {
    ContractContract c = contractContractService.getById(id);
    if (c == null) return R.fail(ResponseCode.PARAMETER_EXCEPTION);
    c.setStatus("REVIEWING");
    c.setReviewerId(Long.valueOf(String.valueOf(body.get("reviewerId"))));
    c.setReviewerName(...);
    c.setReviewComment((String) body.get("reviewComment"));
    contractContractService.updateById(c);
    return R.ok().data(c);
}

// 5.6 通过 / 5.7 驳回：仅 status 不同
//   通过 -> status=APPROVED；驳回 -> status=REJECTED（reviewComment 必填）

// 5.8 归档：写 status=ARCHIVED 并插入一条 contract_archive
@PostMapping("/{id}/archive")
@Transactional(rollbackFor = Exception.class)
public R archive(@PathVariable Long id, @RequestBody Map<String,Object> body) {
    ContractContract c = contractContractService.getById(id);
    if (c == null) return R.fail(ResponseCode.PARAMETER_EXCEPTION);
    c.setStatus("ARCHIVED");
    contractContractService.updateById(c);

    ContractArchive a = new ContractArchive();
    // 拷贝合同字段 + archiveCode=ARC... + archiveLocation + retentionPeriod + expireDate
    contractArchiveService.save(a);
    return R.ok().data(a);
}
```

> 用 `@RequestBody Map<String,Object>` 接收「请求体字段可选」的接口最省事；字段多时建议建 DTO/直接复用实体。

### 4.3 AI 审核（`/ai/*`，异步/模拟）

`AI` 审核是「后台触发 + 查询结果」两段式。

- `POST /ai/review/{contractId}`：把合同状态置为 `AI_REVIEWING`，随后（模拟）生成 `contract_review_result` 和若干 `contract_risk_clause`，再置为 `REVIEWING`。真实项目这里是调用外部大模型；演示项目可以在方法体内同步生成模拟数据。
- `GET /ai/review/result/{contractId}`：按 contractId 查结果与风险列表，组装成文档里的 `summary/keyInfo/risks/comparison/conclusion`。用 `R.ok().data(map)` 逐键拼：

```java
Map<String,Object> data = new HashMap<>();
data.put("contractId", id);
data.put("riskLevel", result.getRiskLevel());
data.put("riskScore", result.getRiskScore());
Map<String,Object> summary = new HashMap<>();
summary.put("totalRisks", ...); summary.put("highRisks", ...);
data.put("summary", summary);
data.put("keyInfo", keyInfo);
data.put("risks", riskList);   // ContractRiskClause 转 List<Map> 或直接List
data.put("conclusion", result.getConclusion());
return R.ok().data(data);
```

### 4.4 风险处理（`/risks/{id}/confirm`、`/risks/{id}/reject`）

更新 `contract_risk_clause.status`（`ACCEPTED` / `REJECTED`）+ 处理时间。直接 `riskClauseService.updateById(...)`。

### 4.5 菜单树 / 角色菜单（`/menu/tree`、`/menu/byRole`、`/role/{id}/menus`）

- 树：查全部菜单，按 `parentId` 组装 `children`。Service 里写个递归/双层循环。
- `byRole`：通过 `sys_role_menu` 关联查该角色有权限的菜单（`SysRoleMenu` 实体 + 关联查询）。
- 分配菜单：先删该角色旧的关系，再批量插入 `SysRoleMenu`（`@Transactional`）。

### 4.6 统计报表（`/statistics/*`）

`StatisticsController` 聚合统计。建议在 `mapper` XML 里写 GROUP BY 的原生 SQL，或 `selectMaps` 返回：

```xml
<select id="countByStatus" resultType="java.util.Map">
    SELECT status, COUNT(*) AS cnt FROM contract_contract GROUP BY status
</select>
```

在 service 里用 `selectMaps` / `listMaps` 拿结果，再 `R.ok().data(map)`。

### 4.7 流程 / 待办（`/process/*`）

`ProcessConfig`（流程配置）、`ProcessNode`（节点）、`ProcessInstance`（实例）、`ProcessTask`（任务）、`ProcessTaskAssign`（任务分配）。
- 待办列表：查 `process_task` 中 `assignee_id = 当前用户` 且 `status=待处理`。
- 处理任务：更新 `process_task` 状态 + 推进 `process_instance` 当前节点。
- 分配任务：更新 `process_task.assignee_id`（可写入 `process_task_assign` 历史）。

### 4.8 集成对接（`/integration/oa`、`/sign`、`/api`）

三者结构一致：配置表 CRUD + 日志表 + 一个「同步/触发」动作。
- 列表/详情/新增/更新/删除：标准 CRUD。
- `GET /integration/oa/{id}/logs`：查 `integration_oa_log`。
- `POST /integration/oa/{id}/sync`、`POST /integration/sign/{contractId}`：调外部系统（演示可用 mock）并写一条 `*_log` 记录。

## 7. 一次开发一个模块的最小流程（照着做即可）

1. **确认实体**字段（`entity/*.java`，含中文注释）。
2. **确认 Mapper** 已继承 `BaseMapper`（若需要连表/聚合再在 XML 里加 SQL）。
3. **补 Service 方法**：在接口加方法，在 `impl` 里用 MyBatis-Plus 实现。
4. **写 Controller**：加方法，`@GetMapping/@PostMapping/@PutMapping/@DeleteMapping`，用 `R` 返回（对象用 `.data(obj)`，分页用 `.data("list",...).data("total",...)`）。
5. **配分页插件**（§2.2），否则分页接口不生效。
6. **权限**：需要按角色/权限限制的加 `@PreAuthorize`。
7. **自测**：启动 `ContractReviewApplication`（8081，`/api` 前缀），带 `Authorization: Bearer <token>` 调接口。

### 常用快速写法（Controller 里一行搞定 CRUD）

```java
// 列表分页
@GetMapping
public R list(@RequestParam(defaultValue="1") int page, @RequestParam(defaultValue="20") int size) {
    Page<X> p = xService.page(new Page<>(page, size));
    return R.ok().data("list", p.getRecords()).data("total", p.getTotal()).data("page", page).data("size", size);
}
// 新增
@PostMapping
public R add(@RequestBody X x) { xService.save(x); return R.ok().data(x); }
// 更新
@PutMapping("/{id}")
public R update(@PathVariable Long id, @RequestBody X x) { x.setId(id); xService.updateById(x); return R.ok().data(true); }
// 删除
@DeleteMapping("/{id}")
public R del(@PathVariable Long id) { xService.removeById(id); return R.ok().data(true); }
```

## 8. 常见问题 / 与前端约定的差异

1. **`timestamp`**：接口文档示例里有 `timestamp`，当前 `R` 没有。前端若强依赖，在 `R` 里加 `private Long timestamp = System.currentTimeMillis();`。
2. **`R.data` 形状**：文档里单对象/数组是 `data` 根部；当前 `R` 是 Map。→ 用 §2.1 增强版 `R`。
3. **登录返回**：文档说登录返回 `id/name/role/roleName/roleId/department`，但当前 `LoginFilter.successfulAuthentication` 只返回 `token` + `username`。要与文档一致，需在`successfulAuthentication`里把 `SecurityUser.getUser()` 的字段也 `data(...)` 塞进去（`SecurityUser.user` 就是完整 `SysUser`）。
4. **分页不生效**：没有分页拦截器，见 §2.2。
5. **`/user/info`**：当前没有该接口，需在 `SysUserController` 加 `@GetMapping("/info")`，用 §2.5 拿当前用户名再从库查 `SysUser` 返回。
6. **请求体字段可选/嵌套**：接口文档里有些请求体字段是「条件可选」，用 `@RequestBody Map<String,Object>` 或建 DTO 最灵活。
